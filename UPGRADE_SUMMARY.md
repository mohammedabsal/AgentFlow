## The Execution Flow

```
User Prompt
    ↓
[Phase 1] Prompt Refiner → Clarified Requirements
    ↓
[Phase 2] Research Agent → Tech Recommendations
    ↓
[Phase 3] Planner → Execution Plan
    ↓
[Phase 4] Architect → System Design
    ↓
[Phase 5] PARALLEL GENERATION (5 agents in parallel)
    ├─ Frontend Agent
    ├─ Backend Agent
    ├─ Database Agent
    ├─ API Agent
    └─ DevOps Agent
    ↓
[Phase 6] Testing Agent → Test Suite
    ↓
WORKSPACE EXECUTION
├─ Create workspace
├─ Write files
├─ Install dependencies
├─ Build project
└─ Run tests
    ↓
ERROR DETECTED?
├─ YES → [Phase 7] Self-Healing Agent → Fixes → Re-execute
└─ NO → COMPLETE
    ↓
Downloadable Production-Ready Project
```

## Getting Started

### 1. Quick Setup (5 minutes)

```bash
# Backend
cd backend
pip install -r requirements.txt
python -m uvicorn app.main:app --reload

# Frontend (new terminal)
cd frontend
npm install
npm run dev

# Visit http://localhost:3000
```

### 2. Generate Your First Project

```
1. Go to http://localhost:3000/builder
2. Enter project name: "MyApp"
3. Describe what you want:
   "Build a social media app with React frontend,
    Node.js backend, PostgreSQL database"
4. Click "Generate Project"
5. Watch the agents work in real-time!
```
